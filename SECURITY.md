# Security policy

## Supported versions

Security fixes are applied to the latest released version of each public
repository. Older releases may no longer receive fixes.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's **Report a vulnerability** action in the Security tab of the
affected repository. Include:

- the affected repository and version or commit;
- steps to reproduce the issue;
- the expected impact;
- any suggested mitigation, if known.

We will acknowledge the report and coordinate disclosure through the private
advisory. Do not include credentials, customer data, production configuration,
or other secrets in a report.
