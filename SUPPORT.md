# Support

Use the issue tracker of the affected repository for reproducible bugs and
focused feature requests.

Before opening an issue:

- check the repository README and existing issues;
- remove credentials, customer names, private topic paths, and production data;
- include the package version, Node.js version, relevant configuration shape,
  and a minimal reproduction when possible.

Public issue trackers are not suitable for vulnerabilities. Report suspected
security issues privately using the instructions in [SECURITY.md](SECURITY.md).
